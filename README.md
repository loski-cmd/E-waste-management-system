Electronic waste (e-waste) is a growing environmental concern in Kenya, with improper disposal leading to pollution and health hazards. Many people are unaware of proper e-waste disposal methods or nearby collection points. This project aims to create a web-based platform to raise awareness about e-waste and facilitate its proper disposal by connecting users with certified e-waste collection centers.
1.	Research Objectives:
o	Investigate factors influencing e-waste disposal in Kenya.
o	Review existing web-based platforms for environmental awareness.
o	Determine the feasibility of integrating the proposed system with existing e-waste collection centers.

2.	System Objectives:
o	Develop a web application that provides information on e-waste and its impacts.
o	Implement a location-based search feature for users to find nearby e-waste collection centers.
o	Provide a submission form for users to report e-waste or request pickup services.
o	Design an admin dashboard for managing collection center data and user submissions
